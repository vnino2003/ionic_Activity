# Activity 1 — Ionic Photo Gallery App

An Ionic Vue 3 mobile application that lets users capture photos using the device camera and view them in a gallery grid. Built with Capacitor for native Android functionality and GitHub Actions for automated APK builds.

---

## What This App Does

- Tap the camera button to take a photo using the device camera
- Photos display in a responsive 2-column grid
- Tap a photo to delete it (via action sheet)
- Photos persist locally on the device using Capacitor Preferences
- Works as a native Android app (APK built via GitHub Actions)

## What is Capacitor?

**Capacitor** is a cross-platform native runtime by Ionic. It takes your web app (HTML/CSS/JS) and wraps it inside a native Android (or iOS) container. This means:

1. You write your app using web technologies (Vue, Ionic components)
2. Capacitor provides **plugins** to access native device features:
   - `@capacitor/camera` — access the device camera to take photos
   - `@capacitor/preferences` — store key-value data locally on the device
3. Capacitor generates an `android/` folder with a full Android Studio project
4. The web app gets copied into `android/app/src/main/assets/public/` during `cap sync`
5. The Android project compiles into an `.apk` file

**Without Capacitor**, a web app cannot access the phone's camera or be installed as a native Android app.

## Key Files Explained

### `src/views/HomePage.vue` — The Main App File

This is where all the photo gallery logic lives. It uses Vue 3 Composition API (`<script setup>`).

**Template section:**
- `<IonFab>` + `<IonFabButton>` — floating camera button at the bottom center
- `<IonGrid>` + `<IonRow>` + `<IonCol size="6">` — responsive 2-column photo grid
- Empty state shown when no photos exist yet

**Script section:**
- `Camera.getPhoto()` — calls the Capacitor Camera plugin to open the device camera
  - `resultType: CameraResultType.Uri` — returns a file URI (not base64)
  - `source: CameraSource.Camera` — forces camera (not photo picker)
  - `quality: 90` — JPEG compression quality
- `Preferences.set()` / `Preferences.get()` — saves/loads photo list as JSON string
- `actionSheetController.create()` — shows delete confirmation when tapping a photo

**Style section:**
- `.photo-card` — rounded corners, shadow, press animation
- `.empty-state` — centered message with camera icon

### `capacitor.config.ts`

```typescript
appId: 'com.example.ioniccalculator'  // Android package identifier
appName: 'Photo Gallery'               // App name on the phone
webDir: 'dist'                          // Where Vite outputs built files
```

### `.github/workflows/build-apk.yml`

This file tells GitHub Actions how to build the APK:

1. **Checkout** — downloads the repo code
2. **Node.js 22** — installs Node to run npm
3. **npm ci** — installs dependencies from package-lock.json
4. **npm run build** — runs Vite to compile Vue app into `dist/`
5. **Java 21** — required by Android Gradle
6. **npx cap sync android** — copies `dist/` into the Android project and registers plugins
7. **gradlew assembleDebug** — compiles the Android project into an APK
8. **Upload artifact** — saves `PhotoGallery.apk` as a downloadable file in GitHub Actions

### `android/app/src/main/AndroidManifest.xml`

Declares the permissions the app needs:
- `CAMERA` — to take photos
- `INTERNET` — for Capacitor's web bridge
- `READ_MEDIA_IMAGES` — to access saved photos
- `WRITE_EXTERNAL_STORAGE` (SDK 29 and below) — legacy storage access

## How to Set Up on Another Laptop

### Prerequisites

- **Node.js 22+** — download from https://nodejs.org
- **Git** — download from https://git-scm.com

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/vnino2003/ionic_Activity.git
cd ionic_Activity

# 2. Install dependencies
npm install

# 3. Run the dev server (browser preview)
npm run dev

# 4. Open in browser
# Go to http://localhost:5173
```

### To Build the APK

You do NOT need Android Studio. Just push to GitHub and the APK builds automatically:

```bash
git add .
git commit -m "your changes"
git push origin main
```

Then go to **GitHub > Actions tab > latest run > Artifacts** and download `PhotoGallery-APK`.

## How the APK Build Works (GitHub Actions)

```
Push to main
    │
    ▼
GitHub Actions starts
    │
    ├── npm ci              → installs node_modules
    ├── npm run build       → Vite compiles Vue app to dist/
    ├── npx cap sync android → copies dist/ into android/app/src/main/assets/public/
    ├── gradlew assembleDebug → compiles Android project into APK
    │
    ▼
PhotoGallery.apk uploaded as artifact (downloadable from Actions tab)
```
